# Changelog

## Unreleased — 2026-11-01

### Added

- Working local application in `app/`, opened by double-clicking `LearnQuick.html`:
  - onboarding with a placement test, and 30 / 60 / 90-study-day plans with a holiday-aware calendar;
  - 25 lessons in 5 phases (300 vocabulary items, 230 exercises, dialogues, grammar hacks);
  - trainers for verbs, preterite vs. imperfect, cognates, false friends, noun gender, describe-it and mixed practice;
  - Leitner spaced repetition;
  - a streak with freezes that never breaks on weekends, holidays or days off;
  - immersion log, device missions, language exchanges and a timed language island;
  - phase checkpoints and a B1 mock exam modelled on the DELE B1;
  - progress metrics derived from recorded activity, and 16 achievements;
  - backup / restore, `.ics` reminder, and English or Spanish interface.
- Node `node:test` suites (20 tests) for the learning engine and content.
- Research and method document (Spanish), student guide (English) and developer guide (Spanish).
- Native desktop app, phase 1 (`desktop/`):
  - a C++20 + Qt 6 CMake project with a Qt Quick start screen, a QML module and design-kit tokens;
  - `.icns` / `.ico` icons rendered from the brand SVG;
  - a `--smoke-test` mode;
  - a CI workflow that builds on Windows and macOS and publishes the Windows build and a universal `.dmg`.
- Native desktop app, phase 2 (`desktop/`, version 0.2.0):
  - `lq_core`, the learning engine in C++20 without Qt: dates, US holidays, study days, schedules, streak and freezes, pace and the demo learner;
  - Catch2 tests ported from the web suite, plus golden-master parity tests against data generated by the web engine;
  - `lq_storage`, a local SQLite database with versioned migrations;
  - a first-run welcome flow in English that asks for the learner's name, their reason for learning Spanish, goals, level and plan length;
  - the Today screen: plan day and tasks, streak and week strip, freezes, pace and projected finish, phases, five-week calendar and the learner's reason;
  - `--demo`, `--today`, `--data-dir` and `--welcome-step` options, and CI screenshots of every screen on both platforms;
  - a CI check that the data exported from the web app is current.
- Native desktop app, phase 3 (`desktop/`, version 0.3.0):
  - the daily plan works end to end: every task opens its screen and ticks itself when done;
  - lessons: course map and a lesson player (words with gender-coloured articles, grammar hack and tables, dialogue, practice, speaking, summary); finished lessons add their words to the review deck;
  - Leitner spaced-repetition review, the eight focus trainers, phase checkpoints with the lessons behind each miss, and the five-part B1 mock exam;
  - answer checking that accepts missing accents with a hint, a first miss that comes back once, and keyboard shortcuts;
  - text-to-speech with the system's Spanish voices (Qt TextToSpeech), at normal or slow speed;
  - engine ports (course loader, answer checking, SRS, conjugator, exercises, mock scoring) with parity tests against the web engine's own output;
  - progress stored in SQLite (schema 2), migrated from the phase 2 database without losing the profile;
  - `--open` and `--require-speech` options, a smoke test per screen and CI screenshots of each screen of the plan.
- Native desktop app, built-in voice (`desktop/`, version 0.3.1):
  - a neural Mexican Spanish voice bundled with the app (Piper `es_MX-ald-medium` on onnxruntime 1.23.2), offline and identical on Windows and macOS; the system voices remain as a fallback;
  - symbols are read as words with either voice: "cansado / cansada" is spoken "cansado o cansada" ("u" before o- and ho-), "+" as "más", parentheses dropped and "…" as a pause;
  - an own Latin-American Spanish phonemizer in C++ that matches espeak-ng on every spoken phrase of the course, without linking espeak-ng (GPL-3.0); a CI check regenerates the espeak-ng reference;
  - voice tests on the real model, and `--require-speech` now synthesizes a word in the packaged app.
- Native desktop app, coach and reflection (`desktop/`, version 0.3.2):
  - a guiding coach: prioritized suggestions built from the learner's own numbers (review pile, days behind, the weakest skill of the last two weeks, a weak lesson, days without speaking, the next checkpoint, how the last session felt), each with its reason and a button that opens the screen; on Today, at the end of every session and on its own screen; the plan itself never changes;
  - every third lesson or practice round, a quick reflection: what the learner enjoyed, how it felt and an optional note; "Not now" postpones it, and the coach screen takes it at any time;
  - mixed practice leans towards the kinds of exercise the learner enjoys (10 drawn from 30 candidates, weights from the last six reflections, never zero), and towards typing or choosing after an easy or hard session;
  - reflections and the session count stored in SQLite (schema 3);
  - the packaged app now ships Qt's offscreen platform plugin, and CI tests it without the runner's Qt installation.
- Native desktop app, on-screen keyboard (`desktop/`, version 0.3.3):
  - every answer box and the mock exam's essay come with a full on-screen keyboard instead of a row of nine accent buttons: QWERTY letters, a highlighted row with á é í ó ú ü ñ ¿ ¡, shift (tap twice to lock), numbers and symbols, delete (hold to repeat), space and Enter;
  - it types at the cursor and replaces a selection without taking the focus, so the physical keyboard keeps working alongside it;
  - in exercises Enter is labelled Check, then Continue, so the main action stays next to the keys even when the window is too short to show the buttons below; in the essay it starts a new line.
- Native desktop app, new voice (`desktop/`, version 0.3.4):
  - the built-in voice is now Supertonic 2, run by the app's own C++ engine on onnxruntime: far more natural and accurate than the Piper voice it replaces (measured on course sentences: 1 % word errors instead of 13 %, naturalness 3.95 instead of 3.09 out of 5);
  - dialogue characters speak with a voice that fits them: women with the clearest female voice, men with two male voices in turn, and "Tú" (written as a man in the course) with a male voice no character shares;
  - numbers are read as words ("305" → "trescientos cinco", "4:30" → "cuatro y media", "B1" → "B uno") and names a Spanish voice misreads are respelled ("Ohio" → "Ojáio");
  - slow playback stretches the natural-pace audio instead of asking the model to speak slower, which blurred the sounds;
  - the voice download grows from about 63 MB to about 260 MB.

### Security

- Before the desktop app moves the database to a new schema, it saves a full copy next to it (`learnquick.sqlite3.v<N>.bak`, one per version); if the copy cannot be written, the database is left untouched.
- Backups are capped at 8 MB and viewing histories at 32 MB, and each restored field gets the type and limits the screens use.
- The web app carries a Content Security Policy that blocks network connections (`connect-src 'none'`) and loads only its own files.
- The certificate PDF is written whole or not at all.
- The GitHub Actions are pinned to commit SHAs, and `scripts/validate_repository.py` fails on a tracked key, a personal email address or a learner's data file.
